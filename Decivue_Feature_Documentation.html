1. Executive Summary

Decivue is a full-stack Decision Intelligence Platform that enables organizations to make, track, and govern strategic decisions with clarity and confidence. It goes beyond simple task management by adding health monitoring, conflict detection, AI-powered insights, relationship mapping, and governance workflows to every decision.

Unlike traditional tools that treat decisions as static records, Decivue treats them as living entities that evolve over time — tracking confidence drift, detecting assumption violations, monitoring review schedules, and surfacing conflicts before they become problems.

Key Differentiators

  • Decision Health Score: A dynamic, multi-factor score that degrades over time based on confidence, time decay, conflicts, and assumption validity
  • Conflict Detection Engine: Automatically detects resource, budget, timeline, and risk strategy conflicts when decisions are linked
  • Visual Decision Tree: An interactive D3-based tree showing hierarchical relationships with health-colored nodes
  • AI Decision Assistant: Context-aware chatbot providing analysis and recommendations for each decision
  • Governance Workflows: Built-in approval, review, and reaffirmation workflows with audit logging
  • Kanban Board: Drag-and-drop workflow management with color-coded columns for decision lifecycle tracking

4. Core Features

4.1 Dashboard & Analytics

Frontend Backend

The main dashboard provides a bird's-eye view of all organizational decisions with actionable insights and real-time health monitoring.

Key Capabilities

  • Summary Statistics: Active decisions, under review, critical alerts, and average confidence displayed as stat cards
  • Health Score Overview: Visual confidence gauge showing the aggregate health of all decisions
  • Review Alerts: Smart alert cards highlighting overdue reviews, degrading confidence, and assumption violations
  • Quick Navigation: Direct access to any decision, the visual tree, or the decision library
  • Health Color Coding: Green (Healthy 70-100%), Yellow (At Risk 40-69%), Red (Critical 0-39%)

4.2 Decision Creation Wizard

Frontend Backend

A guided, multi-step wizard that walks users through creating a well-structured decision with all necessary context.

Wizard Steps

  1. Decision Statement: Title, detailed context/description, decision type (Strategic, Tactical, Operational, Risk Mitigation), category, and impact level
  2. Context & Assumptions: Dynamic assumption list — add, edit, remove assumptions that underpin the decision. Each assumption is tracked independently for validity monitoring
  3. Confidence & Risk: Set initial confidence score (0-100%), risk level, priority level (LOW/MEDIUM/HIGH/CRITICAL), and estimated cost/effort
  4. Review Settings: Configure review frequency (days), set target review date, lifecycle state, and governance requirements

Technical Details

  • Step-by-step validation prevents advancing without required fields
  • Real-time preview of decision data as it's entered
  • On submission, creates the Decision record + associated Assumption records + initial AuditLog entry

4.3 Decision Detail View

Frontend Backend AI

The most comprehensive view in the platform — a tabbed interface showing every aspect of a decision's lifecycle.

Tabs

  • Overview: Health panel with live score, confidence gauge, risk tags, lifecycle badges, owner/reviewer info, and governance status
  • Sub-Decisions: Hierarchical breakdown into smaller actionable tasks with individual progress tracking and completion marking
  • Timeline: Chronological history of all actions (creation, reviews, reaffirmations, notes, assumption changes) with relative timestamps
  • Relationships: Interactive D3 force-directed graph showing decision dependencies, conflicts, and relationships with directional arrows and color coding
  • Reasoning Tree: Auto-generated visual tree showing supporting factors, risks, considerations, and alternatives for the decision
  • Versions: Full version history with diff comparison showing what changed between versions
  • Attachments: Upload/download file attachments (documents, images, spreadsheets) linked to the decision
  • Assistant: AI-powered chatbot providing contextual analysis and recommendations specific to this decision

Action Controls

  • Reaffirm Decision: Reset review clock and boost confidence, creating a version snapshot
  • Add Review Note: Append commentary to the decision timeline
  • Update Assumptions: Add new assumptions with automatic versioning
  • Mark Reviewed: Complete the review process and update lifecycle state
  • Request Approval: Trigger governance approval workflow
  • Edit/Delete Decision: Full CRUD with cascade deletion for sub-decisions

4.6 Decision Health Monitoring

Backend Algorithm

A sophisticated multi-factor health scoring engine that treats every decision as a living entity requiring ongoing monitoring.

Health Score Components

FactorWeightDescription
Base Confidence40%Initial confidence set during creation (0-100%)
Time Decay25%Score degrades over time since last review (configurable frequency)
Conflict Penalty15%Penalty for each active conflict relationship detected
Assumption Validity10%Score based on ratio of valid vs. broken assumptions
Review Recency10%Bonus for recently reviewed decisions, penalty for overdue ones

Health Statuses

  • 🟢 Healthy (70-100%): Decision is well-maintained and current
  • 🟡 At Risk (40-69%): Decision needs attention — review or assumption check recommended
  • 🔴 Critical (0-39%): Decision is stale, conflicted, or assumptions have broken down

Technical Implementation

  • Health is calculated deterministically from initial_confidence to prevent cumulative drift
  • Score is recalculated on every view and after any modification
  • Stored persistently in the current_confidence field for dashboard queries

4.7 Conflict Detection Engine

Backend Algorithm

Automatically detects potential conflicts when decisions are linked together, surfacing warnings before they cause downstream problems.

Conflict Types Detected

  • Resource Overlap: Two decisions targeting the same category with the same priority level, competing for shared resources
  • Timeline Overlap: Review dates within 30 days of each other, creating review bottlenecks
  • Budget Conflict: Multiple high-impact, high-priority decisions competing for budget allocation
  • Opposite Risk Strategies: Conflicting risk mitigation approaches between linked decisions (CRITICAL severity)
  • Conflicting Assumptions: Decisions with many assumptions flagged for manual cross-checking

Severity Levels

  • CRITICAL: Opposite risk strategies — immediate attention required
  • WARNING: Resource overlap or budget conflicts — should be reviewed
  • INFO: Timeline proximity or assumption overlap — awareness only

4.8 Relationship & Dependency Graph

Frontend Backend Interactive

An interactive D3.js force-directed graph showing relationships between decisions with directional arrows and relationship-type coloring.

Relationship Types

  • DEPENDS_ON: Decision A cannot proceed without Decision B (blue links)
  • ENABLES: Decision A enables or unblocks Decision B (green links)
  • CONFLICTS_WITH: Decisions are in tension or opposition (red links)
  • RELATED_TO: General association between decisions (gray links)
  • SUPERSEDES: Decision A replaces or overrides Decision B (purple links)

Visualization Features

  • Draggable nodes with physics simulation
  • Directional arrows showing relationship direction
  • Color-coded nodes and edges by relationship type
  • Hover tooltips with decision details
  • Modal for adding new relationships with conflict pre-check

4.9 Kanban Board

Frontend Backend Drag & Drop

A full-screen, drag-and-drop Kanban board for managing decision workflows with color-coded columns.

Columns

  • DECISIONS (Purple #A78BFA): All existing decisions — the backlog/pool
  • TO-DO (Orange #F4A261): Decisions planned for action
  • IN PROGRESS (Cyan #81D4E8): Decisions actively being worked on
  • COMPLETED (Yellow #E9D66B): Resolved and closed decisions

Key Capabilities

  • Drag & Drop: Smooth drag-and-drop between columns using @dnd-kit with pointer sensor and 5px activation distance
  • Optimistic Updates: UI updates instantly on drop — API call runs in background without page refresh
  • Colorful Cards: Each card inherits the column's background color for clear visual grouping
  • Decision Titles: Cards display actual decision titles from the database (not risk labels)
  • Full-Screen Mode: Sidebar automatically hides, content goes edge-to-edge via LayoutContext
  • Back Navigation: Dedicated back arrow button to return to the workspace list view
  • Drag Overlay: Rotated, scaled shadow card during drag for premium feel

Frontend Backend Database

Full team workspace with member management, role assignment, and team-scoped decision views.

Team Dashboard Features

  • Team Overview: Stats cards showing active decisions, under review, critical alerts, and average confidence per team
  • Decision Grid: Responsive card grid (1/2/3 columns) showing team decisions with health badges
  • View Toggle: Switch between List view and Kanban board view
  • Member Avatars: Visual representation of team members with role badges

4.11 Version History & Audit Trail

Backend Database

Complete change tracking with version snapshots and detailed comparison capabilities.

Version Tracking

  • Automatic Versioning: Every significant change (reaffirm, review, assumption edit) creates a numbered version snapshot
  • Version Comparison: Side-by-side diff view showing what changed between any two versions
  • Change Descriptions: Each version includes a human-readable description of what changed
  • Snapshot Data: Full decision state captured in JSON for point-in-time recovery

Audit Logging

  • Action Types: CREATE, UPDATE, REAFFIRM, REVIEW, NOTE_ADDED, ASSUMPTION_ADDED, ASSUMPTION_EDITED, ASSUMPTION_DELETED, PROGRESS_UPDATE, APPROVAL_REQUESTED
  • User Attribution: Tracks who performed each action
  • Timeline Integration: All audit events appear in the decision's timeline view

4.12 AI Decision Assistant (Chatbot)

Frontend AI

A context-aware AI assistant embedded directly within each decision's detail view, providing analysis and recommendations.

Key Capabilities

  • Inline Tab: Accessible as a dedicated "Assistant" tab within the decision detail page — no floating widgets
  • Context-Aware: Receives the full decision context (title, description, assumptions, health score, relationships) for informed responses
  • Analysis Types: Risk analysis, assumption validation, stakeholder impact assessment, timeline recommendations
  • Chat Interface: Standard chat UI with message history, typing indicators, and formatted responses
  • Decision-Scoped: Each decision has its own separate chat conversation

4.13 Governance & Review Workflows

Frontend Backend

Built-in governance framework for decisions that require formal approval and periodic review cycles.

Governance Features

  • Governance Badge: Visual indicator showing if a decision requires governance approval
  • Governance Guard: Prevents certain actions until governance approval is obtained
  • Governance Action Panel: Centralized panel for governance actions (approve, reject, escalate)
  • Review Intelligence: Backend service that generates smart review alerts based on review frequency, last review date, and health status
  • Review Alerts: Dashboard cards highlighting decisions that are overdue for review
  • Approval Workflow: Request → Review → Approve/Reject flow with full audit trail

4.14 Reasoning Tree Generator

Backend Frontend Algorithm

Automatically generates a structured reasoning tree for any decision, breaking it down into supporting factors, risks, and alternatives.

Tree Structure

  • Root Node: The decision statement itself
  • Supporting Factors: Evidence and rationale in favor of the decision
  • Risk Factors: Identified risks and potential downsides
  • Assumptions: Key assumptions the decision depends on
  • Alternatives: Other options that were considered
  • Considerations: Contextual factors that influence the decision

Visualization

  • Expandable/collapsible tree nodes
  • Color-coded by category (green for supporting, red for risks, blue for considerations)
  • Interactive panel within the Decision Detail view

4.15 Attachments & File Management

Frontend Backend

Full file attachment system allowing documents, images, and spreadsheets to be linked to decisions.

Key Capabilities

  • Upload: Drag-and-drop or click-to-upload file interface
  • File Types: Supports documents (PDF, DOCX), images (PNG, JPG), spreadsheets (XLSX, CSV), and more
  • File Preview: Preview images and documents inline
  • Download: Direct download links for all attachments
  • File Metadata: Tracks upload date, file size, MIME type, and uploader
  • Backend Storage: Files stored on the server via Multer middleware with dedicated attachment routes

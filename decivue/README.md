**Decivue** is a premium strategic decision intelligence platform designed to synthesize complex organizational intelligence into actionable nodes. It moves beyond simple tracking, providing a sophisticated framework for reasoning, dependency mapping, and collective decision architecture.

---

## ✨ Core Pillars

### 1. Intelligence Dashboard
An immersive, real-time command center monitoring the "Integrity" and "Confidence" of your decision portfolio.
- **Portfolio Health**: Visual health markers and trend analysis.
- **Synchronization Alerts**: proactive notifications for nodes requiring re-calibration (review).
- **High-Impact Tracking**: Dedicated focus on critical strategic pathways.

### 2. Knowledge Inventory (Decision Library)
A lexical repository of all stored intelligence nodes, searchable by impact, integrity, and category.
- **Node Matrix**: Grid-based visualization of strategic nodes.
- **Advanced Filtering**: Filter by integrity (health), impact (risk), and timeframes.
- **Rapid Establishment**: streamlined wizard for creating new intelligence nodes.

### 3. Strategic Focus Mode
Deep-dive analysis environment for individual nodes, featuring multi-layered reasoning visualization.
- **Reasoning Architecture**: Hierarchical tree visualization of the logic behind a decision.
- **Dependency Network**: Spider-graph mapping of relationships (Derived from, Supported by, Blocked by).
- **Topology Mapping**: Full-scale visual network of the decision's environment using `xyflow`.

### 4. Team Space (Collective Intelligence)
Collaborative workspaces where teams can synchronize on shared strategic matrices.
- **Flow Visualization**: Kanban-style view for monitoring decision lifecycles.
- **Role Architecture**: Ownership and Reviewer assignments for high-stakes nodes.
- **Analytical Snapshots**: High-level stats on team-wide strategic compliance.

## 🛠️ Technology Stack

- **Framework**: [React 18](https://reactjs.org/) with [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS + [Tailwind CSS](https://tailwindcss.com/) with a custom HSL-based premium design system.
- **Animations**: [Framer Motion](https://www.framer.com/motion/) for smooth transitions and interactive micro-animations.
- **State Management**: [Zustand](https://github.com/pmndrs/zustand) for reactive, performant state sync.
- **Visualization**: [XYFlow](https://xyflow.com/), [D3.js](https://d3js.org/), and [Dagre](https://github.com/dagrejs/dagre) for complex graph layouts.
- **Icons**: [Lucide React](https://lucide.dev/) for a clean, consistent icon language.
- **Data Handling**: [Axios](https://axios-http.com/) and [date-fns](https://date-fns.org/).

---

## 🎨 Design Philosophy: "Cognitive Premium"

Decivue utilizes a bespoke design system built on HSL variables, allowing for:
- **Glassmorphism**: Sophisticated depth and layering using backdrop blurs.
- **Dynamic Color Palettes**: Semantic colors (Indigo/Violet for intelligence, Emerald for health, Amber for review, Rose for risk).
- **Interactive Micro-animations**: Hover states that feel "alive" and responsive.
- **Modern Typography**: Bold tracking and tight leading for an authoritative, expert-system feel.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (current LTS)
- [npm](https://www.npmjs.com/) or [bun](https://bun.sh/)

### Installation

1. Clone the repository:
   ```bash
   git clone [repository-url]
   cd decivue
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Initialize the development environment:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
